# GensouMarket 文档索引

本文档用于统一说明 `./doc` 下各类文档的归档位置。

## 目录结构

- `project/`
  - 项目说明、功能介绍、安装与使用文档
- `archive/`
  - 历史规划、版本想法、已结档设计文档
- `guides/`
  - 通用经验总结、踩坑记录、可复用方法论
- `tasks/`
  - 从规划中拆分出的任务书，供后续直接分派执行
- `tests/`
  - 人工测试文档、回归记录、验收清单

## 使用约定

- 新增说明类文档，优先放入 `project/` 或 `guides/`
- 新增阶段规划或历史草案，优先放入 `archive/`
- 需要直接交给 Claude 或其他实例执行的内容，先整理为 `tasks/` 下的独立任务书
- 人工测试、回归清单、验收记录统一放入 `tests/`
- `CLAUDE.md` 固定保留在项目根目录，其余普通 Markdown 默认不再堆放在根目录
