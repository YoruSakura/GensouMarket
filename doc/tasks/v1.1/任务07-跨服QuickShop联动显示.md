# 任务 07：跨服 QuickShop 联动显示

- 状态：`后备/低优先级`
- 优先级：低
- 依赖：`任务06-QuickShop软依赖联动.md`

## 目标

在跨服环境下，正确展示同一玩家在多个子服的 QuickShop 联动店铺实例。

## 核心原则

- 同步层按店铺实例处理
- 展示层可按物品聚合
- 不能把多实例粗暴合并为一条状态

## 实现前必须先定的规则

- 实例唯一标识是 `shop_id` 还是坐标
- 状态同步频率
- 跨服冲突处理策略
- 展示页聚合规则
- 修改动作精确命中实例的交互方式

## 数据建议

- `source`
- `server_id`
- `shop_id`
- `owner_uuid`
- `item_key`
- `price`
- `stock`
- `status`
- `last_sync_time`
