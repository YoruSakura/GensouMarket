# 任务 03：统一模块开关一期

- 状态：`可直接实现`
- 优先级：高
- 依赖：无

## 目标

将插件功能统一纳入模块开关体系，使服主可以关闭某一功能入口而不影响其余模块。

## 本期范围

- 新增以下模块开关
  - `market.enabled`
  - `auction.enabled`
  - `mail.enabled`
  - `shop.enabled`
  - `recycle.enabled`
  - `trade.enabled`
  - `personal-shop.enabled`
  - `cluster.enabled` 继续保留
- 命令层统一提示“该功能未启用”
- 主菜单按开关动态显示或置灰
- 被关闭模块不注册无意义入口
- 相关定时任务按模块开关控制是否执行

## 当前代码现实

- `shop.enabled`、`recycle.enabled`、`trade.enabled` 已存在
- `market`、`auction`、`mail`、`personal-shop` 尚未纳入统一开关体系
- 启动时仍是全量初始化、全量监听、全量定时任务

## 建议实现原则

- 区分“模块关闭”与“系统不可用”
- 关闭模块时优先关闭主动入口，不要顺手破坏底层能力
- 重载（`reload`）后能立即生效的部分尽量立即生效
- 无法安全热生效的部分要在文档里明确

## 验收标准

- 配置中可显式关闭各模块
- 被关闭模块的命令不可主动使用
- 主菜单和子界面不再出现无效入口
- 对应后台逻辑不再无意义执行
- 重载（`reload`）后开关行为符合预期

## 备注

- 该任务适合作为 1.1 主线第一步
- 完成后再做跨服兼容会更稳
